# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование — [Semantic Versioning](https://semver.org/lang/ru/).

## [0.1.3] — 2026-10-20

### Исправлено

- **Графический мастер не запускался на РЕД ОС 8.** GUI был собран против
  libadwaita 1.4 (`adw::NavigationView`, `adw::ToolbarView`,
  `adw::NavigationPage`): на РЕД ОС 8 стоит libadwaita 1.2, и процесс падал при
  старте с `undefined symbol: adw_navigation_view_new`. Навигация переписана на
  `gtk::Stack` + `adw::HeaderBar`, диалог сообщений — на `adw::Window` вместо
  `adw::MessageDialog` (libadwaita 1.2), поле пароля — на `gtk::Entry` вместо
  `gtk::PasswordEntry` (GTK 4.4). Мастер теперь использует только GTK4 4.0 и
  libadwaita 1.0.
- **RPM собирался только с CLI.** В spec bcond `gui` был объявлен как
  `bcond_with`, поэтому обычная сборка `rpmbuild -bb` давала пакет без
  графической части, а `migration-master gui` отвечал «графический интерфейс
  недоступен». Теперь GUI включён по умолчанию, CLI-only вариант получается
  флагом `--without gui`.
- При запуске GUI без графической сессии приложение молча завершалось — теперь
  выводится причина (нет `DISPLAY`/`WAYLAND_DISPLAY`, запуск из-под `sudo`) и
  пишется запись в журнал.
- Архив больше не включает сам себя: файл `.rmm` внутри сканируемого
  каталога исключается из упаковки (иначе прошлый архив попадал в новый).
- Относительный путь к архиву в GUI считается от домашнего каталога, поддержан
  префикс `~`.

### Упаковка и CI

- `Recommends: gtk4, libadwaita` — установщик подтянет графические библиотеки
  из репозитория, если они там есть.
- В `%check` добавлена проверка, что бинарник линкует GTK4: пакет без
  графической части больше не собирается молча.
- Тесты в `%check` запускаются с той же фичей `gui`, что и сборка.
- CI проверяет, что бинарник не импортирует API GTK4/libadwaita новее базовых
  версий (иначе пакет снова окажется неработоспособным на РЕД ОС 8).
- `clippy` теперь запускается с `--all-features`: GUI-код раньше вообще не
  компилировался в CI, поэтому в релиз попадал вызов API libadwaita 1.4.

## [0.1.2] — 2026-10-09

- Релизный RPM по умолчанию собирается с GUI (GTK4 + libadwaita).
- CI: линковка GUI через `cargo-zigbuild` с потолком glibc 2.28 — пакет
  устанавливается на РЕД ОС независимо от версии glibc хоста CI.
- CI: smoke-тест GUI-бинарника (команда `gui` запускает GTK-код).

## [0.1.1] — 2026-10-05

- Опция сборки `--with musl`: статическая линковка CLI и helper, бинарники не
  зависят от glibc целевой системы.
- Пакет устанавливается на любую РЕД ОС независимо от версии glibc (раньше
  установка падала из-за `libc.so.6(GLIBC_2.xx)` из чужого окружения CI).

## [0.1.0] — 2026-10-04

- Установка `migration-master-helper`, политики PolicyKit, иконки и примеров
  конфигурации.
- Подключены юнит-тесты в `%check`.
- Первая версия пакета: создание зашифрованных архивов, миграция по SSH,
  перенос настроек приложений и SSH-ключей, интеграция с CUPS.
