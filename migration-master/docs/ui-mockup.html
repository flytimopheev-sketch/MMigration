Migration Master — макет интерфейса

Визуализация GTK4 / libadwaita мастера миграции пользователя для РЕД ОС Linux. Реализовано в src/ui/gtk_app.rs.

Макет отражает реальные виджеты приложения: adw::NavigationView + adw::ToolbarView + HeaderBar, группы adw::PreferencesGroup/ActionRow, gtk::ProgressBar. Панели сверху и слева — служебные, только для анализа макета.

Параметры

✓
Пробный запуск (dry-run)
Проверить соединение и план без передачи

Поток операции

проверка соединения→ анализ диска→ rsync / tar→ SHA-256→ атомарная замена

Долгая операция выполняется в фоновом потоке, интерфейс не блокируется; прогресс обновляется через gtk::ProgressBar и таймер GLib.
